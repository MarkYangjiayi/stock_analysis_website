## 重现方式

在 `frontend` 目录执行，Playwright 会启动前后端，使用脚本严格限定的 `data/screener_e2e.db` 专用测试库：

```bash
npm run lint
npm run test
npm run test:e2e
```

生产模式必须先把测试 API 地址编译到前端：

```bash
NEXT_PUBLIC_API_URL=http://127.0.0.1:8010 npm run build
PLAYWRIGHT_USE_PRODUCTION=1 npm run test:e2e -- --project=chromium -g 'captures responsive|keeps keyboard focus|keeps working valuation|opens assumptions'
```

`PLAYWRIGHT_USE_PRODUCTION=1` 让测试启动 `next start`；默认仍为 `next dev`。生产部署时应按目标环境重新构建，不能直接使用嵌入本地测试 API 地址的构建产物。
