按用户授权实施 V01–V04、V06–V10；**V05 银行、保险、REIT 的业务模型分流继续 Hold**。这是本地代码、迁移、数据修正记录及工程验证的交付，尚未部署到 finbrain.icu。原诊断证据保持冻结，见 [综合问题清单](../valuation_cross_sector_2026-09-10/consolidated_issues.md)。

所有公司共用计算规则。没有 NVDA 专属的增长、Beta、折现率或终值参数，也没有以市价、Simply Wall St 或 Alpha Spread 的价格作为拟合目标。逐公司的官方财务事实修正与模型参数分开管理。

## 统一参数与计算含义

- Beta = clamp((2×observed+1)/3, 0.5, 2.5)。缺失 Beta 才使用 1；零点连续。原本的日收益复权、基准对齐、一年窗口、最少 126 个共同观测和异常收益隔离不改变。
- 历史 Base 取收入 TTM 同比、3 年与 5 年增速的中位数，默认范围 −20% 至 20%；Bear/Bull 的宽度来自未截断信号，最终可编辑范围 −20% 至 50%。情景不是概率区间；终值成熟增长仍沿用配置，须低于 WACC 至少 0.5 个百分点。
- 十年默认路径采用年末折现。5 年高增长后另 5 年逐步减速。反向 DCF 求的是**初始五年增长率**，不是整个十年的固定 CAGR。
- 显式经营模型：FCFF=EBIT−max(EBIT,0)×税率−capex+D&A−Δ营运资本。亏损不自动产生即期税收返还。使用显式预测时停用历史增长控制及单变量反向增长推算；终值敏感性同步重新计算再投资。
- 股权桥：EV + 可加回现金 − 债务 + 其他有来源的资产／权益调整。未知少数股东公允价值不直接用账面值替代。`equity_bridge.complete=false` 表示尚未取得完整桥表；历史估算并不是已完成所有资产／权益勾稽的“确定合理价格”。

## 官方财务事实修正包

[financial_reconciliations.json](financial_reconciliations.json) 只保存有来源的事实、定义、可得日期和原始财务报表哈希。本轮没有把它们自动写入本地业务数据库或线上数据库。

|---|---:|---|
| NVDA | 33.366 | 借款，排除经营租赁；期间 2026-07-26；24.285bn 明确标为季度稀释加权平均股数 |
| WMT | 57.243 | 借款＋融资租赁，排除经营租赁 |

| O | 30.651653 | 合并借款净额，不含融资租赁；946.202m 期末普通股；REIT 模型仍 Hold |
| MSFT | 106.888 | 借款＋融资租赁，排除经营租赁；7.427bn 期末普通股 |

O 的融资租赁及权益比例债务不能与合并债务混称；它的财务纠错不等于本次新增 REIT 估值。NVDA 官方 FCF 与 CFO−capex 存在设备本金支付定义差异，保留桥表含义，不将其直接判为算术错误。

每个修正字段附来源链接。新申报、原始报表变化或证据日期尚未到达时，旧包不可应用；带失效包的估值明确返回原因。同步写入一份新原始报表会移除旧包，需要重新核验并导入。不会跨季度沿用某只股票的固定修正数。

## 跨行业回归结果

[锁定清单](validation_manifest.json) 包含原 33 股＋新增 ORCL、DIS、NKE、PEP、ABT、COP、LMT、SHW、AEP、EQIX。新增名单在查看 v2 输出前锁定，但不是随机总体样本，也不是历史预测验证集。

[regression_results.json](regression_results.json)：43 股中有 42 股的完整供应商缓存可供重建；PGR 缓存缺失，属于 Hold 的保险范围，明确列为缺失，没有补造。排除金融、REIT 和 UNH 保险业务后，共 35 股，28 股满足历史模式及正普通股权益残值条件，7 股继续不可估。

- 6 股：AAPL 缺少完整实际利息；AMZN、NEE、DUK、SO、ORCL 的规范化起始 FCFF 非正。不可估不等于公司无价值；可以通过有来源且满足约束的经营预测计算。
- 所有可计算对象均通过独立十年折现、情景排序、敏感性中心检查；有可用股价且能反解时，反向解回代也通过。保留全体缺失及负数案例，未因结果“不好看”移除。
- AEP 的历史假设下普通股权益残值为负，作为诊断字段保留；每股估值返回 null 和原因，敏感性中的非正权益单元格也不显示为负股价。
- 新增十股的缓存没有同期行情和 Beta 档案：Beta 用明确标记的回退，未编造同日价格，因此未对这些股票声称反向估值或历史风险参数有效性。
- 样本结果并非全线上升：例如 LIN、UNP、FCX、NEM 的估算降低。NVDA 在冻结输入、已复核债务、声明的股数代理及统一参数下约 $109.81，仍明显偏离市价；这个差异不是验收失败，也不是另行调参的理由。这不是当前线上或实时估值。
- JSON 记录旧债务单独替换产生的每股桥表变化，其他同时变化不作机械相加归因。旧 v1 的 31 个可计算输出另已完整复现，历史报告和快照未覆盖。

以上只验证工程一致性和输入边界；**不证明任何股票的公允价值、预测准确率或未来收益**。

`validate_valuation_repairs.py` 默认只读本地冻结缓存，无网络、无数据库写入。它重建包含修正包的隔离财务对象，并记录每份源缓存哈希。缺失的普通企业缓存导致失败；本轮 Hold 的 PGR 单列为数据缺口。

应用代码部署时需要先执行迁移 `0019_valuation_forecasts`。已保存的情景增加可空 JSON 列，现有记录保留；降级会删除显式预测 JSON，保留旧增长／利率列。

```bash
.venv/bin/python -m alembic upgrade head
# 先在目标环境预览，检查财报原始哈希是否匹配：
.venv/bin/python scripts/reconcile_valuation_inputs.py docs/valuation_repair_2026-09-10/financial_reconciliations.json
# 匹配全部记录后，才执行明确的写入命令：
.venv/bin/python scripts/reconcile_valuation_inputs.py docs/valuation_repair_2026-09-10/financial_reconciliations.json --apply
```

导入命令默认预览；`--apply` 要求全部记录匹配，任一缺失／不匹配则整批不写。原始报表字段不覆盖，只附独立校验包。迁移和事实导入在测试数据库验证，**没有执行生产迁移、数据写入或发布**。
