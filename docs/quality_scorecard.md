# 质量评分卡

`services/quality_scorecard.py` 用最近一份存储的 EODHD 基本面数据（筛选器本来就会拉取的那份）里最多 6 个财年的年报，算出 5 项支柱、综合分、Piotroski F 分数和 Altman Z。结果写进筛选器字段，个股页 Overview 的"质量评分卡"面板也展示同一套结果（`GET /api/stocks/{ticker}/quality`）。不额外调用数据供应商。

这些值没有时点历史，只用于筛选和展示，不用于回测。

## 打分方法

每个指标设一个"弱"阈值和一个"强"阈值：达到"弱"阈值记 0 分，达到"强"阈值记 100 分，中间线性插值。支柱分取其指标得分的平均。

综合分取有数据的支柱的平均，需要满足两个条件：
- 至少 3 项支柱有数据；
- 至少 3 个财年。

只有两年年报时，几个只看最新一年的指标也能凑出 3 项支柱，但这样算出的分数没有意义。

| 综合分 | 评级 |
|---|---|
| ≥ 75 | 优 |
| 60–75 | 良 |
| 45–60 | 中 |
| < 45 | 弱 |

阈值固定，不按行业分位打分。好处是一只股票的分数不随当天其他股票的发布情况变化。代价是行业差异没有被抹平，例如 REIT 的 ROIC 天然偏低。

| 支柱 | 指标 | 弱 → 强 | 说明 |
|---|---|---|---|
| 盈利能力 | ROIC 均值 | 3% → 15% | 税后 EBIT / 投入资本（供应商 netInvestedCapital；缺失时用权益 + 有息负债） |
| | ROIC ≥ 8% 的年份占比 | 40% → 100% | 看稳定性，不只看平均 |
| 增长持续性 | 收入复合增速 | 0% → 12% | 窗口首尾 |
| | 收入增长年份占比 | 50% → 100% | |
| 现金转化 | FCF / 净利润 | 50% → 110% | 窗口合计；净利润合计不为正时不计 |
| | 应计比率 | +5% → −10% | (净利润 − 经营现金流) / 平均总资产，最新财年 |
| 资产负债表 | 净债务 / EBITDA | 4× → 0× | 净现金记 100 分；有净债务而 EBITDA 不为正记 0 分 |
| | 利息覆盖倍数 | 2× → 12× | EBIT / 利息；无有息负债记 100 分；有负债但利息未披露时不计（如苹果） |
| 资本配置 | 股本变化 | +10% → −5% | 窗口内总股本变化，回购为负 |
| | 股权激励 / 收入 | 10% → 1% | 最新财年 |

2026-10-20 用生产环境存储的 2,532 份数据校准：
- 2,524 只算出了综合分；
- 十分位为 30 / 37 / 42 / 48 / 52 / 58 / 64 / 72 / 80；
- 评级"优"有 417 只。

几只示例股票的综合分：

| 股票 | 综合分 |
|---|---|
| MA | 94 |
| V | 93 |
| AMAT | 89 |
| GOOG | 87 |
| MSFT | 86 |
| AAPL | 81 |
| BA | 31 |
| INTC | 22 |

## 行业模板

模板按 `General.Industry` 选择（与筛选器的行业名一致）：

- **金融**（银行、保险（不含保险经纪）、资本市场、抵押贷款、金融综合企业）：
  - 负债是这类公司的经营原料，所以盈利能力改用 ROE 均值（6% → 15%）；
  - 不算现金转化、资产负债表、F 分数和 Altman Z。
  - 综合分只基于 3 项支柱，和其他公司不完全可比。
- **REIT**：
  - 折旧和结构性负债会扭曲现金转化和净债务/EBITDA，所以现金转化不算，资产负债表只看利息覆盖；
  - 不算 Altman Z。
- **其他公司**：全部指标都算。

已知局限：
- "信贷服务"（Credit Services）既有 V、MA 这样的支付网络，也有发卡放贷机构，目前都按普通公司处理。
- 银行模板的完整设计（如 P/B–ROE）仍待 V05 跟进。

## Piotroski F 分数

比较最新财年和上一财年，共 9 项检验：
- 资产收益率为正；
- 经营现金流为正；
- 资产收益率上升；
- 经营现金流高于净利润；
- 长期负债率未上升；
- 流动比率上升；
- 未增发股份；
- 毛利率上升；
- 资产周转率上升。

资产用期末值，是常见的简化做法。9 项必须全部能判断才给分，否则只显示能判断的项数。只算 8 项会看起来像低分。

## Altman Z

用原始公式，股权取市值：

Z = 1.2 × 营运资本/总资产 + 1.4 × 留存收益/总资产 + 3.3 × EBIT/总资产 + 0.6 × 市值/总负债 + 1.0 × 收入/总资产

区间：
- 大于 2.99 为安全；
- 1.81–2.99 为灰色；
- 小于 1.81 为困境。

大量回购的成熟公司留存收益可能为负，Z 值会因此偏低。例如 ORCL 为 1.75，落在困境区，应结合资产负债表支柱一起看。

## 字段与回填

筛选器新增这些字段，都归在 Fundamental 分类下：
- 综合分与支柱：`quality_score`，以及 `quality_profitability` / `quality_growth` / `quality_cash_conversion` / `quality_balance_sheet` / `quality_capital_allocation` 五项支柱分；
- 其他分数：`piotroski_f_score`、`altman_z`；
- 原始指标：`roic_5y_avg`、`fcf_conversion_5y`、`share_change_5y`。

迁移为 `0027_quality_scorecard`。部署后可以在服务器上回填缓存，用的是已存储的原始数据，不调用外部 API：

```bash
docker compose exec worker python scripts/rederive_quality_scorecard.py
```

不回填的话，字段会随每只股票每周的基本面刷新逐步补齐。
