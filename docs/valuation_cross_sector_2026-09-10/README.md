评估日期：2026-09-10。网站股价日期统一为 2026-09-09；财务期末以每家公司返回值为准。本轮只新增诊断脚本和证据，不修改线上估值模型或默认参数。

后续补充：[综合问题清单](consolidated_issues.md) 加入相同 11 家的 Alpha Spread 方法对照、UNH/O 官方勾稽及十项待办。按用户要求，所有生产修改保持 Hold；本页保留最初诊断快照，后续核查结论以补充清单中的明确说明为准。

**样本与评估纪律**

在批量获取结果前，于 2026-09-10 14:28:37 UTC 固定了 [manifest.json](manifest.json) 中的 33 家公司及统一扰动规则。每个广义板块三家公司；选样覆盖业务类型，但偏向美国大型上市公司，属于目的性诊断样本，不代表全市场随机抽样。NVDA 已在此前讨论，整个面板均视为已观察的诊断样本，不冒称为盲测或留出集。

以公开默认情景为准，不读取个人保存的假设。股价只是描述性参照，SWS 是另一模型的输出；都不是真实内在价值标签，不用于拟合参数。后续若选择模型，应另锁未观察股票和历史时间段，并使用当时已公布的数据及分析师预测，避免未来信息和幸存者偏差。

**覆盖与独立复算**

- 33/33 公司成功取得两个公开接口的数据，31/33 当前模型可计算；AMZN、NEE 的估算 TTM FCFF 为负，返回 unavailable，不把它当作零估值。
- 31 个 Base 输出都与仓库中的生产计算函数一致；另一套独立写出的折现计算最大误差低于每股 $0.00000001。
- 33 组季度自由现金流之和与决策接口 TTM FCF 一致。两个接口共享上游来源，这只证明内部一致，不能证明原始财报数据全部正确。
- 金融板块三家公司与 REIT 三家公司只作适用性审计，不并入普通企业 FCFF 的汇总。其余 27 家中有 25 家可计算，但这一子样本仍含保险相关业务、周期性、租赁及高资本开支等需进一步核查的情形，不是已经清洗完毕的准确性验证集。

**发现一：Beta 处理在零附近不连续，是跨板块问题**

本次 Beta 来源为：供应商基本面 Beta 6 家、本地一年 Beta 16 家、市场 Beta=1 回退 11 家。经 [筛选器原始 Beta](beta_screener.json) 核对，11 次回退均有可见的负一年 Beta，并非简单缺数据：VZ、MCD、PG、KO、WMT、JNJ、PGR、XOM、SO、AMT、O。

当前规则在供应商 Beta 不可用时，仅接受 `0 < local_beta <= 3`；负数或零被替换为 1.0。接近零的正数却直接采用。例如 LIN 的本地 Beta 0.0876 被采用，WACC 4.84%；PG 的 -0.0499 则回退到 1，WACC 10.05%。二者业务和资本结构也不同，这组公司数值不是单变量因果实验。

为隔离这一边界，另以完全相同的无债公司输入调用实际 WACC 函数：Beta=-0.01 得到 10.808% WACC，Beta=+0.01 得到 4.868%。仅输入 Beta 小幅跨过零点，折现率就变化 5.94 个百分点。复算输入和结果见 [beta_boundary_reproduction.json](beta_boundary_reproduction.json)。

这说明应审计 Beta 的窗口、供应商覆盖和统一回退规则。负的样本回归 Beta 不等于数据必然错误；非常小的正 Beta 也未必适合直接外推为长期资本成本。需要评估连续的收缩估计、行业先验或统一边界策略，不针对某个 ticker 指定 Beta，也不简单把所有负值原样塞进长期 DCF。

相关代码：[Beta 选择](../../services/decision_support.py)、[WACC 计算](../../services/valuation_assumptions.py)。

**发现二：17/33 存在债务口径差异，不能直接任选一个字段作为真值**

按同一财务日期比较两个接口的债务，差异超过财务页债务 0.5% 的有 17 家；其中 6 家差异超过 10%。小差异可能来自租赁分类或字段定义，并不一律判为错误。下表为六个较大差异，单位十亿美元。

| 公司 | DCF 所用债务 | 财务页债务 | 当前判断 |
|---|---:|---:|---|
| NVDA | 1.509 | 38.860 | 借款漏计已由上一轮官方财报核查支持 |
| MSFT | 66.504 | 128.808 | 需拆开借款、融资租赁、经营租赁，不能只比较合计 |
| WMT | 16.543 | 73.755 | 官方借款与融资租赁合计 57.243，DCF 数字明显不完整 |
| UNH | 3.827 | 73.328 | 待逐项对照官方借款和租赁 |
| BAC | 392.197 | 732.060 | 先解决银行模型适用性，再核对债务范围 |
| O | 28.418 | 2.760 | 财务页反而明显较小；两个方向都需审计 |

WMT 是新增的独立官方核查：2026-07-31 短期借款 10.479、当期长期债务 3.470、长期债务 36.462、当期及长期融资租赁 0.880+5.952，合计 57.243；经营租赁 1.714+14.798=16.512。两种合计分别是 57.243 与 73.755，取决于是否资本化经营租赁，而 DCF 所用 16.543 不能覆盖借款。[Walmart 官方财报](https://stock.walmart.com/sec-filings/all-sec-filings/content/0000104169-26-000145/earningsreleasefy27q2.htm)

微软官方主表借款为 9.227+31.067=40.294，租赁需进一步读附注；因此本报告不把微软财务页 128.808 直接宣布为 DCF 的正确扣减值。[Microsoft 官方财报](https://www.microsoft.com/en-us/investor/earnings/fy-2026-q4/press-release-webcast)

修复应同时统一现金流、债务与租赁利息处理；把经营租赁从股权桥扣除，却不调整仍含租金支出的现金流，会产生新的重复计量问题。当前差异统计只是定位入口，未完成 33 家逐份官方报表的字段审计。

**发现三：金融公司“可计算”不代表模型可用**

JPM 当前 Base 为 $2,432.14，股价 $354.71；BAC 为 $466.94，股价 $62.67，分别约 6.86 和 7.45 倍。JPM 的输入还把 $2.623 万亿作为现金与短期投资加回，并把约 $761.8 亿税后利息加入现金流。对银行而言，这些项目与存款、融资和业务运营相连，不能机械套用普通企业的剩余现金及资本结构含义。

银行、保险宜先做权益估值、股利/剩余收益及监管资本再投资框架的适用性判断。REIT 则应明确维护性资本开支、AFFO/FFO 与 NAV 口径。按经济特征路由模型是通用规则；按单一股票目标价选模型是另一回事。本轮未取得每家 SWS 的完整模型展开，因此不声称逐股复现其金融或 REIT 方法。[Damodaran：金融服务公司估值](https://pages.stern.nyu.edu/~adamodar/pdfiles/papers/finfirm09.pdf)、[SWS 多模型说明](https://github.com/SimplyWallSt/Company-Analysis-Model/blob/master/MODEL.markdown#value)

UNH 虽归医疗板块，也有保险相关业务；CAT 等公司的融资业务也值得进一步拆分。因此 sector 只能作为第一层分组，业务特征应参与适用性判断。

**发现四：增长上限只影响少数样本；统一拉长预测期并不能解决其他问题**

20% 基准上限在 33 个样本中触发 3 次：NVDA、LLY、BAC；剔除金融与 REIT 后的 25 家可计算公司只触发 2 次。移除这一层上限、仍保留原来的 50% 信号截尾及其他参数：NVDA Base 从 $78.28 变为 $202.61；LLY 从 $1,206.51 变为 $1,911.85；BAC 从 $466.94 变为 $484.45。这是定位规则影响的实验，不是推荐值。它也说明全面放宽上限会抬高已经偏高的输出。

另外做了事先固定的十年渐降实验：保留前五年增长率、FCFF、WACC、终值增长和股权桥；第 6–10 年的增长为 `g_terminal + (g_base - g_terminal) × 0.7^(year-5)`，第十一年起进入原永续增长。0.7 是统一的诊断参数，未优化，且不声称等同 SWS 的完整方法。

| 统一实验 | 非金融、非 REIT 的可计算样本结果 |
|---|---|
| 加入第 6–10 年减速过渡 | 每股估值变化中位数 +8.2% |
| WACC 降低 1 个百分点，其余保持 | 每股估值变化中位数 +19.4% |
| 科技三家公司加入减速过渡 | 变化中位数 +17.7% |
| 必需消费三家公司加入减速过渡 | 变化中位数仅 +3.3% |

两种实验分别相对当前 Base 计算，不把影响相加；它们是敏感性分析，不是预测准确率。对于当前增长低于终值增长的公司，渐降公式实际是逐步恢复增长，也可能降低估值，例如 VZ、HON。公用事业的低贴现率及较高债务，使股权值对 WACC 更敏感。

**后续验证顺序与通过标准**

1. 输入层先完成 debt/lease/cash/share 的官方报表勾稽；缺失字段不作为零，部分分项不遮蔽完整合计。统一所有页面的口径与来源标记。每个真实缺陷至少在多个行业重现，修复后再在原样本回归。
2. 依据业务经济特征决定 FCFF、权益模型、REIT 模型或暂不可估值；统一输出原因，避免银行“数值可算”被展示成可信的内在价值。
3. 核查一年 Beta 本身，再锁定少数统一的 Beta/风险溢价处理候选，比较跨时点稳定性、零点连续性、来源覆盖和极端敏感性。禁止按 ticker 或“最接近价格”选择参数。
4. 输入层通过后比较统一五年、十年渐降、分析师逐年预测等少量候选；前瞻估计记录人数、更新时间、覆盖不足与 fallback，必要时对周期利润和再投资作统一建模。
5. 另设未观察股票和滚动历史窗口。先比较预测现金流与后来实现的现金流、区间覆盖率和修订稳定性，再观察持有期收益、行业暴露及交易成本后的表现。股价距离、SWS 距离仅作描述，不作为唯一评分标准。

这一轮完成横截面诊断与外部输出对照，没有声称证明哪套模型在未来更准确；也没有选定任何新参数、按行业优化参数或上线修改。
