# 日报质量修正版验收

版本：`cross-asset-v2.1`。日期：2026-09-15（新加坡）。

## 已完成

1. **降低归因确定性**：报告展示已保存新闻原标题与链接，附“尚未验证为此次涨跌原因”。不再直接复述 AI 的“核心原因”“获利了结”判断。无新闻时明确无法确认原因。生成端提示词同时要求事实、关联和证据边界分开；既有保存结果不被覆盖。
2. **逐项时间与新鲜度**：异动行增加纽约报价日期、时间及 EST/EDT。盘前、旧快照、不同交易日、缺失时区、未来时间、收盘待更新都有明确提示；顶层显示有多少个股报价不适合作当前行情。
3. **缩短默认展示**：依据飞书消息技能的组件规范，日报使用 Card 2.0，首屏保留核心变化和数据提示；行情、个股新闻、早晚对比/日历/口径分三组可展开。资产明细不删减，原始证据和完整文本继续保留。
4. **消除带符号零**：SPY 的实际前后变动 −0.003923% 显示为“微降（不足 0.01%）”，不再显示 `-0.00%`；实际零显示 `0.00%`。同时移除尾部多余的 `>`，让报价行和新闻行明确分行。
