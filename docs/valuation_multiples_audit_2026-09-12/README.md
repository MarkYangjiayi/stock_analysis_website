# 历史估值倍数跨行业抽样审计

审计日期：2026-09-12（新加坡）。检查对象为 finbrain.icu 的线上返回值，代码版本为 PR #52 合并后的 main。结论：**拆股修复生效，但仍有财务字段、季度汇总和行业口径问题，不能将六类倍数统一认定为可靠。** 本次新增问题尚未修改生产计算逻辑。

## 样本与验证方法

抽样 10 家公司、9 个行业：MSFT、INTC、JPM、XOM、JNJ、WMT、CAT、NEE、AMT、AMZN。

- 对每家公司读取真实股票页 API；首次读取未完成拆股验证的样本，按接口限速重新读取，10 家最终均返回 `split_history_verified=true`。不能把首次返回的空值算作检验通过。
- 统一历史比较日为 **2025-03-31**，对应当时已披露的财务数据。WMT 使用截至 2025-01-31 的财年，其他样本此时最新财期为 2024-12-31。另抽查线上最新可用价格日 **2026-09-10**。
- 独立价格源使用 Yahoo chart 的当日 `close`，不使用包含股息复权的 `adjclose`。两个日期合计 20 个价格点与网站倍数反推的计算价格一致，差异仅为浮点精度。[Yahoo 报价接口样例：MSFT 2025-03-31](https://query1.finance.yahoo.com/v8/finance/chart/MSFT?period1=1743379200&period2=1743465600&interval=1d)
- 财务外部源使用 SEC Company Facts 中的 10-K/10-Q，按实际财期对齐，排除检查日之后申报的事实；必要时直接读公司年报。TTM 优先使用年度金额，跨财年用“上一完整年度 + 本年累计 − 上年同期累计”。SEC 标签必须按公司业务选择，不能把同名字段在所有行业中机械套用。数据事实、申报日期、accession 和标签保留在 JSON 证据文件中。[SEC API 说明](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)
- P/E 以官方 diluted EPS 重算，与本站 provider share proxy 的估计口径可能有小幅差异。P/S、P/B、P/FCF 另做“保持网站股数不变，仅替换 SEC 分母”的受控比较，便于区分股数 proxy 和财务映射错误。这种受控比较不等于独立验证了精确历史市值。
- 扫描本地已提供的历史中，自 2020 年起、财务 basis 未变的相邻观测：P/E、P/S、P/B、P/FCF 的涨跌相对价格涨跌没有超过 10% 的异常残差。此项只排查明显的拆股/价格归一化异常，不能发现平滑但错误的分母。
- 7 家公司的线上价格历史仅从 2024-01-11 开始。只有 MSFT、WMT、AMZN 提供更长历史，因此不能据此声称验证了全部公司过去几十年的曲线。

## 已确认的异常

### 1. NEE：2024 年 P/FCF 漏掉主要业务的投资支出

网站 2025-03-31 的 P/FCF 为 **30.80×**，分母是 **47.46 亿美元** FCF。其年度 CFO 为 132.60 亿，扣除的资本支出仅为 85.14 亿。

NEE 年报现金流表列出：FPL 79.92 亿、NEER 独立电力及其他投资 162.15 亿、核燃料 3.99 亿、其他资本支出 1.23 亿。网站的 85.14 亿恰好等于除 NEER 之外的三项之和。集团官网采用的资本投入合计为 247.29 亿；按此完整投资支出口径，CFO 减投入为 **-114.69 亿美元**，P/FCF 应显示 N/M，不能把 30.80× 解释为集团自由现金流倍数。NEER 行同时包含独立电力及其他投资，需要保留项目范围说明，不能简单冒充一个通用 PP&E 标签。[NEE 2024 10-K](https://www.sec.gov/Archives/edgar/data/753308/000075330825000011/nee-20241231.htm)、[公司资本投入统计](https://www.investor.nexteraenergy.com/fixed-income-investors/cash-flow-quality-and-leverage)

这是完整 CFO 配上不完整资本支出范围的实质问题。线上最新可用价格日 NEE 的 P/FCF 已为空，但不能据此忽略历史错误。其最新 TTM 在本次获取的旧 CIK SEC facts 中无法完整覆盖，未将最近一期标记为独立核验通过。

### 2. JNJ：季度资本支出汇总对不上年报，最新数值仍有偏差

2024 年四个季度的 EODHD capex 合计 **62.07 亿美元**，SEC 年报为 **44.24 亿**；CFO 均为 242.66 亿，故网站 FCF 为 180.59 亿，而按 SEC CFO−PP&E 得到 **198.42 亿**。保持网站股数 proxy 不变，2025-03-31 的 P/FCF 应约 **20.29×**，网站为 **22.29×**，高约 **9.87%**。[JNJ 2024 10-K](https://www.sec.gov/Archives/edgar/data/200406/000020040625000038/jnj-20241229.htm)、[官方业绩公告及 FCF 定义](https://www.investor.jnj.com/investor-news/news-details/2025/Johnson--Johnson-Reports-Q4-and-Full-Year-2024-Results/default.aspx)

2026-09-10 的问题仍然存在：SEC 重建 TTM CFO 为 276.08 亿、capex 为 53.64 亿、FCF 为 **222.44 亿**；网站 FCF 为 **187.08 亿**。保持网站股数不变，P/FCF 为 **29.22×**，网站显示 **34.74×**，偏高约 **18.90%**。证据使用 2025 10-K 与 2026 半年报及其中的上年同期数，详见最新比较 JSON。已确认季度汇总不一致，但尚未断言上游错误究竟来自累计值、年份还是重述混用。

### 3. JPM：P/S 的收入口径不匹配，最新 P/FCF 连正负号都不一致

2024 年网站 TTM revenue 为 **2,707.73 亿美元**，官方 reported total net revenue 为 **1,775.56 亿**。保持网站股数不变，2025-03-31 的 P/S 从 **2.58×**变为约 **3.93×**；若再使用 SEC 期末实际股数，约为 **3.87×**。不能把网站的分母直接当作通常银行估值使用的净收入，也不能简单减去利息费用就认为完成了规范化。[JPM 官方 4Q24 补充报表](https://www.jpmorganchase.com/content/dam/jpmc/jpmorgan-chase-and-co/investor-relations/documents/quarterly-earnings/2024/4th-quarter/42092156-03a0-428c-9692-d7e844b063a1.pdf)

线上最新可用价格日更明显：网站 P/S **3.32×**，同股数、SEC 净收入分母重算约 **4.95×**。网站 P/FCF 为 **11.47×**，但 SEC TTM CFO 为 **-1,625.34 亿美元**，已为负值，不能支持正的 FCF 倍数。银行现金流受存贷款、交易资产和资金业务影响，不宜照搬工业企业的 CFO−capex 估值。现有代码屏蔽了银行 EV 倍数，但没有同样处理 P/FCF。[JPM 2026 半年报](https://www.sec.gov/Archives/edgar/data/19617/000162828026054343/jpm-20260630.htm)

### 4. AMT：出售印度业务后的重述口径混合

截至 2025-03-31，网站四个季度收入合计 **108.043 亿美元**，但当时已公开的 2024 年报持续经营收入为 **101.272 亿**。SEC 同一份 2024 年报将 Q1/Q2 收入分别重述为 **25.126 亿 / 25.447 亿**；网站仍使用含已出售业务的原始 **28.341 亿 / 29.003 亿**，再拼接已经剔除该业务的 Q3/Q4，差额精确为 **6.771 亿**。[AMT 2024 年度结果](https://americantower.gcs-web.com/news-releases/news-release-details/american-tower-corporation-reports-fourth-quarter-and-full-20)

保持股数和 EV 其他项目不变，2025-03-31 的 P/S 应约 **10.06×**，网站 **9.43×**；EV/Revenue 应约 **14.21×**，网站 **13.32×**。这是不同业务范围的季度混合，不只是市场波动或合理的估值差异。最新收入和 FCF 的对照已接近，但历史段仍有问题。

## 可解释的差异及未完成的独立验证

- **MSFT、WMT**：两个抽样日的收入、CFO−capex 和账面权益分母能与 SEC 对齐。实际期末股数与 provider 股数 proxy 的差别仍会影响市值倍数；不能称为精确市值验证。
- **CAT**：2024 年 PP&E 资本支出 19.88 亿，还须加上对外出租设备投入 12.27 亿，合计 32.15 亿，便与网站 FCF 88.20 亿吻合。若只抓第一个 capex 标签，会把正常口径差别误报成数据错误。P/B 使用集团权益扣除明确披露的少数股东权益，对照差异小于 0.02%。
- **AMZN**：2024 年 SEC CFO 1,158.77 亿减总设备投入 829.99 亿，等于网站 FCF **328.78 亿**。公司公开 FCF 382.19 亿还计入资产销售和激励等净额，不能不调口径就对比两个 P/FCF。最近 TTM CFO−总投入为负，网站正确显示 N/M。[AMZN 2024 年报](https://www.sec.gov/Archives/edgar/data/1018724/000101872425000004/amzn-20241231.htm)
- **XOM**：2024 年 P/E 与官方 EPS 对齐，CFO−PP&E 的 **307.16 亿**也一致；官方公布的另一种 FCF 343.62 亿包括不同的投资/处置调整。网站收入 3,392.47 亿与报表总收入及其他收益 3,495.85 亿不是同一范围；需要明确采用净销售、联营收益和其他收益中的哪些项目。不能把这一差别直接当成拆股或价格错误。最新 XOM 切换 CIK，单个现有主体 facts 无法构成完整 TTM，本次未把最新 P/E 标记为外部验证通过。[XOM 2024 年度公告](https://corporate.exxonmobil.com/news/news-releases/2025/0131_exxonmobil-announces-2024-results)
- **INTC**：两个抽样日的 EPS 均为负，网站不绘制 P/E 是合理行为。2024 年 FCF 为负、最新 TTM FCF 28.31 亿转正，网站对应的空值/高 P/FCF 有财务分母依据；高倍数本身不足以判错。
- **EV/Revenue、EV/EBITDA 尚不能统一判定通过**。债务和租赁范围尚未规范：MSFT 2024 年网站 debt 1,029.09 亿可精确分解为借款 449.70 亿 + 融资租赁 360.77 亿 + 经营租赁 218.62 亿；XOM 的 debt 则没有同样加入经营租赁。EBITDA 同样需要区分非经营损益和各家公司 adjusted EBITDA。举例：AMZN 最新网站 EBITDA 为 2,539.97 亿；以 SEC“营业利润 + 报表折旧摊销”作另一种明确的计算口径，得到 1,689.12 亿，同一 EV 下分别是 **11.21× / 16.85×**。这说明口径敏感，不能把后者不加说明地当作唯一正确值，也不能声称前者已经交叉核验通过。[MSFT 租赁附注](https://www.sec.gov/Archives/edgar/data/789019/000095017025010491/msft-20241231.htm)

## 处理优先级

1. 为季度数据增加与同范围年度/YTD 财报的勾稽校验。出现重大差异时，相关曲线应显示缺口和具体原因；不能等曲线发生跳变才发现问题。
2. 修正 NEE 集团资本投入范围、JNJ 季度现金流映射，处理 AMT 持续经营重述。修正必须遵守已知披露日期，不能把未来重述提前应用到过去。
3. 银行单独定义收入和普通股股东盈利，评估关闭银行 P/FCF；现有 EV 屏蔽保留。
4. 明确股份、租赁、非控股权益和 EBITDA 的展示口径，再做 EV 倍数跨平台对照。

## 证据及复现

- `comparison.json`：2025-03-31 的线上值、独立报价、SEC 财务事实、原始申报 accession、受控比较。
- `comparison-2026-09-10.json`：2026-09-10 对照；缺失 SEC 事实保留为 null，不能算作核验通过。
- `controlled-comparison.md`：两日期的 P/S、P/B、P/FCF 分母对照；N/M 表示已知分母非正或经济上无意义；“未核验”表示外部证据不足，两者区分展示。
- `reproduce.py`：基于本机采样文件重算。默认历史日期，设置 `AUDIT_ANCHOR=2026-09-10` 重算最新日期。原始 API 响应保存在项目 `data/valuation_audit_2026-09-12/`，原有 SEC facts 缓存为 `data/sec_mapping_cache/sec/`。脚本不会修改生产数据或计算规则。

原始缓存不随本报告提交；新检出的仓库可以查看上述 JSON 中保留的事实和计算结果，完整重跑脚本则需要先备齐上述本机缓存。发布前已重跑两个日期，输出与本目录保存的 JSON 完全一致，并检查了 20 个样本的披露日期和价格一致性。

本报告是有针对性的抽样审计，不是全股票池、全历史或全部 EV 口径的认证。
